This work is an original physical edition of Rain Blooms, an on-chain generative artwork released on Art Blocks Studio (2026). It comprises an aluminum frame, an LED matrix panel, and an embedded microcontroller running the cellular automaton algorithm designed by the artist. The work is unique in its parameter configuration; no two editions produce identical outputs.

本作品は、2026年にArt Blocks Studioにてリリースされたオンチェーン・ジェネレイティブアート《Rain Blooms》のフィジカルエディションのオリジナル作品です。アルミフレーム、LEDマトリクスパネル、アーティストが設計したセルオートマトン・アルゴリズムを実行する組み込みマイコンにより構成されます。本作品はパラメータ設定において固有であり、いかなる2点のエディションも同一の出力を生成しません。
