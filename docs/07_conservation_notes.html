Overview / 概要

This document provides conservation guidance for the long-term care of Rain Blooms Lattice. It covers routine maintenance, component replacement policy, acceptable repair procedures, and contacts for technical support. It should be read in conjunction with Document 03 (Identity Document), which defines which components are work-defining and which may be substituted.

本文書は、《Rain Blooms Lattice》の長期的な保存管理に関するガイダンスを提供します。日常的なメンテナンス、部品交換方針、許容される修理手順、技術サポートの連絡先を網羅しています。どのコンポーネントが作品を定義し、どれが代替可能かを定義する文書03（作品同一性文書）と併せて参照してください。

02

Routine Maintenance / 日常的なメンテナンス

2.1 Cleaning the LED Panel / LEDパネルの清掃

  1. 1Power off the work and disconnect from mains. · 作品の電源を切り、コンセントから抜く。
  2. 2Allow the panel to cool for 5 minutes. · パネルが冷えるまで5分待つ。
  3. 3Wipe gently with a dry, lint-free microfibre cloth. · 乾いた、けば立ちのないマイクロファイバークロスで優しく拭く。
  4. 4Do not use any liquid cleaner, solvent, or compressed air directly on the panel. · パネルに液体クリーナー、溶剤、または圧縮空気を直接使用しないこと。

2.2 Cleaning the Aluminum Case / アルミケースの清掃

  • If the aluminum case around the panel is touched with bare hands, gently wipe the affected area with a lint-free microfibre cloth lightly moistened with alcohol to prevent skin oils from adhering permanently. · パネル外周のアルミケースを素手で触れた場合は、皮脂が固着しないように、アルコールを軽く染み込ませた毛羽立ちのないマイクロファイバークロスで該当箇所を優しく拭く。

2.3 Storage / 保管

  • Store in a climate-controlled environment: temperature 10–25 °C, relative humidity 40–60%. · 温度10〜25 °C、相対湿度40〜60%の温湿度管理された環境に保管すること。
  • Cover the LED panel with air cushion before packing. · 梱包前にLEDパネルをエアクッションで覆うこと。
  • Store upright, not stacked. · 立てて保管し、積み重ねないこと。
  • Power on and operate the work for at least 1 hour per month during extended storage to prevent component degradation from disuse. · 長期保管中は月に最低1時間は電源を入れて動作させること。
03

Component Replacement Policy / 部品交換方針

Per Document 03, the work's identity resides in the algorithm, not specific hardware. · 文書03に基づき、作品の同一性はアルゴリズムに宿り、特定のハードウェアにはありません。

Component / 部品 Policy / 方針
Power supply / 電源ユニット FREE SUBSTITUTION
Any supply meeting the electrical spec (DC 5–5.1 V, 5 A). No consultation required. · 電気仕様（DC 5–5.1V、5A）を満たす任意のユニットへの交換可。相談不要。
LED panel / LEDパネル CONSULT NEORT++ FIRST
64×64 LED panel only, with equivalent color and brightness. Larger or smaller resolutions are not permitted. Contact NEORT++ before purchase to confirm driver compatibility. · 64×64 LED固定。同等の色・輝度特性を持つものに限る。より大きい、または小さい解像度への変更は認められない。購入前にドライバ互換性を確認すること。
Microcontroller / マイコン CONSULT NEORT++ FIRST · FIRMWARE REFLASH REQUIRED
Firmware must be reflashed from Document 05 archive. Contact NEORT++ before sourcing to confirm firmware compatibility. · 文書05アーカイブからファームウェアを再書き込み。調達前にNEORT++に相談。
Frame / フレーム REPAIR ACCEPTABLE · FULL REPLACEMENT: CONSULT ARTIST
Minor damage may be repaired or refinished. Full replacement requires artist consultation to maintain structural proportions. · 軽微な損傷は修理・再仕上げ可。完全交換にはアーティストへの相談が必要。

4.3 Firmware Installation Procedure / プログラム書き込み方法

Use this procedure only for conservation, restoration, or authorized microcontroller replacement. Do not modify the firmware logic or edition-specific parameters. · この手順は、保存・修復、または承認されたマイコン交換時のみ使用すること。ファームウェアのロジックやエディション固有パラメータは改変しないこと。

  1. 1Install the latest Arduino IDE on the maintenance computer. · メンテナンス用PCに最新のArduino IDEをインストールする。
  2. 2In Arduino IDE, install the ESP32 board support package through Boards Manager. · Arduino IDEのBoards ManagerからESP32ボードサポートをインストールする。
  3. 3In Library Manager, install Adafruit Protomatter and Adafruit GFX Library. · Library ManagerからAdafruit ProtomatterとAdafruit GFX Libraryをインストールする。
  4. 4Connect the MatrixPortal S3 to the computer with a USB data cable. Do not use a charge-only cable. · MatrixPortal S3をUSBデータケーブルでPCに接続する。充電専用ケーブルは使用しない。
  5. 5In Tools → Board, select Adafruit MatrixPortal ESP32-S3. · Tools → BoardでAdafruit MatrixPortal ESP32-S3を選択する。
  6. 6In Tools → Port, select the COM port that appears when the board is connected. · Tools → Portで、ボード接続時に表示されるCOMポートを選択する。
  7. 7Set Upload Mode to UART0 / Hardware CDC when this option is available. Keep USB CDC On Boot at the board guide default unless troubleshooting requires a change. · 設定項目がある場合、Upload ModeはUART0 / Hardware CDCにする。USB CDC On Bootは、トラブルシュートが必要な場合を除き、ボードガイドの既定値のままとする。
  8. 8Open the archived .ino firmware for the relevant edition from Document 05 and click Upload. · 文書05のアーカイブから該当エディションの.inoファームウェアを開き、Uploadを実行する。
  9. 9After upload completes, press the reset button on the MatrixPortal S3 if the program does not start automatically. · 書き込み完了後にプログラムが自動起動しない場合は、MatrixPortal S3のリセットボタンを押す。
  10. 10Verify that the LED panel initializes, displays a 64×64 image, and begins the intended continuous computation. · LEDパネルが初期化され、64×64の映像が表示され、意図された継続計算が開始されることを確認する。

If upload fails, first confirm that the correct board and port are selected, then try a different USB data cable, a different USB port, or a USB hub. If needed, hold BOOT, press Reset, release BOOT, and retry the upload.

書き込みに失敗した場合は、まず正しいボードとポートが選択されていることを確認する。そのうえで、別のUSBデータケーブル、別のUSBポート、またはUSBハブを試す。必要に応じて、BOOTを押したままResetを押し、BOOTを離してから再度書き込みを行う。

Known Limitations and Wear / 既知の限界と消耗

  • LED brightness degradation — LEDs gradually dim over their service life. Up to 30% reduction from initial output is within normal operation. Beyond 50% reduction, panel replacement should be considered.
    LEDの輝度低下 — 初期出力から30%までの低下は通常動作範囲内。50%を超える場合はパネル交換を検討。
  • Electrolytic capacitors — The power supply contains capacitors with a typical service life of 10–15 years. If the work shows unstable behavior (flickering, unexpected resets), capacitor aging is the first thing to investigate.
    電解コンデンサ — 電源ユニットのコンデンサの寿命は通常10〜15年。不安定な動作（フリッカー、リセット）が見られる場合は最初に確認すること。
  • Long-term firmware storage — Flash memory data retention is rated at 20+ years. The USB archive (Document 05) should be copied to new media every 5–10 years as a precaution.
    長期ファームウェア保存 — フラッシュメモリのデータ保持期間は20年以上。USBアーカイブは予防措置として5〜10年ごとに新しいメディアにコピーすること。
